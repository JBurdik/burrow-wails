# Burrow

Burrow is a desktop IDE that coordinates coding agents in terminal tabs and structured chats. Reach for it to delegate work, fan out independent tasks, supervise an agent, use worktrees, or control the running IDE.

This file is deliberately only a stub: the full guide is served by the binary that runs the commands, so it cannot drift. Read it with `burrow skills get burrow`.
